- Fixed a latent double-free (issue #643). Several simulation modules own dynamically-allocated output messages that are freed in their destructors, but inherited the compiler-generated copy operations. Copying such a module shallow-copied the raw message pointers, so two instances would each free the same messages. These modules are now non-copyable: :ref:`eclipse`, :ref:`spiceInterface`, :ref:`reactionWheelStateEffector`, :ref:`msmForceTorque`, :ref:`mappingInstrument`, :ref:`vizInterface`, :ref:`dataFileToViz`, :ref:`pinholeCamera`, :ref:`spacecraftLocation`, :ref:`groundLocation`, :ref:`groundMapping`, :ref:`spacecraftChargingEquilibrium`, :ref:`planetEphemeris`, :ref:`stripLocation`, and the :ref:`magneticFieldBase` and :ref:`atmosphereBase` base classes (which also makes their derived field and atmosphere models non-copyable).
